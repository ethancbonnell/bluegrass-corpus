# bluegrass-corpus
Repository for ongoing research into bluegrass harmony. 

I've got to build this out but step 1 of the process is getting ~100 tunes in the data file. Each tune is encoded with a basic harmony and melody (and occasionally alternates) designed to sorta represent a "real book" version of the harmony and melody (not direct transcriptions). Variant files will be input as they become applicable, and information about prominent recordings are also available in the files. I'll add more documentation in the near-medium future.
